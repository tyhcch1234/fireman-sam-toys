# 消防員山姆玩具圖鑑 · Fireman Sam Toy Atlas

一個靜態網頁，把全球市場上的 **Fireman Sam（消防員山姆）** 玩具整理成可搜尋、可篩選的分類圖鑑，附商品照片、參考售價、原廠商品頁與官方影片。

## 內容

- **24 件玩具**，分為七類：人偶角色、消防車與交通工具、消防局場景、聲光電子、幼兒系列、圖書拼圖
- **3 個市場**：英國（Amazon UK，GBP）、美國（Amazon US，USD）、加拿大（Amazon CA，CAD）
- 每張卡顯示當地標價 + 依參考匯率換算的港幣約數
- 支援關鍵字搜尋、分類篩選、價格排序
- 3 條官方／玩家 YouTube 影片，點擊才載入 iframe（不拖慢首頁）

## 技術

- 單一 `index.html`，內嵌 CSS / JS，無框架、無建置步驟
- 圖片存放於 `assets/toys/`，首次載入後可離線瀏覽版面
- `catalog.py` 為資料來源清單（ASIN、售價、分類），方便日後更新

## 資料說明

商品名稱、售價、圖片與連結來自各零售商公開商品頁，擷取日期 **2026-11-01**；售價與匯率會浮動，實際價格以下單時的頁面為準。本專案為非官方粉絲整理，與 Mattel、Simba Toys 及任何零售商無關；圖片版權屬原權利人，僅作產品識別用途。
